Bilateral ODA after aid cuts — visualisations preview

This page previews the seventeen interactive figures accompanying the 2026 CGD paper Modelling bilateral ODA flows to 2028, hosted by the Center for Global Development. View the source repository on GitHub.

These figures must be served over HTTP. Each one fetches a binary payload, and fetch() is blocked on file://, so opening this page from disk shows seventeen fail states rather than seventeen charts. To review locally, run python -m http.server 8000 from the repository root and open http://localhost:8000/preview.html.

Note: this preview page is for review only. The production digital note may use different surrounding text and spacing. Iframe heights are content-driven and update automatically; the height attribute on each frame is a loading placeholder measured at 1200px, not a fixed height.

The payload client is fail-closed: a figure that cannot verify the manifest, an axis hash or a blob checksum renders a visible fail state rather than an empty chart. A fail state on this page is a real finding, not a preview artefact.
